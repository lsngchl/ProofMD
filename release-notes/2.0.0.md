# ProofMD 2.0.0

ProofMD 2.0.0 renames the Windows app from LeanMD to ProofMD. Releases now use
versioned Git tags and GitHub Releases, starting with `v2.0.0`.

## Changes

- Rename the app, executable, package metadata, installer, and file associations
  to ProofMD.
- Upgrade registered LeanMD installations while preserving existing Markdown
  default-app choices through compatibility registrations.
- Transfer window position and WebView2 settings on first launch, including the
  saved light/dark theme. Existing ProofMD settings take precedence.
- Retain ordinary Markdown navigation, math rendering, reading-position
  restoration, unresolved markers, and ProofFold disclosures and maps.
- Add tests for profile and theme migration, installer upgrades, and preservation
  of existing file associations.

## Install or upgrade

1. Install the Microsoft .NET 10 Desktop Runtime for Windows x64 and the Microsoft
   Edge WebView2 Runtime if they are not already available.
2. Download `ProofMD-2.0.0-win-x64.zip` and extract the complete folder.
3. Close LeanMD and ProofMD, then run `Install-ProofMD.cmd` in the extracted
   `ProofMD-2.0.0` folder. Installation is per-user and requires no administrator
   privileges.
4. Open ProofMD. The first launch transfers settings from LeanMD when needed.

ProofFold uses an adjacent `prooffold.json` manifest.
