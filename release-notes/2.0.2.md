# ProofMD 2.0.2

ProofMD 2.0.2 completes the document-opening fix by making optional ProofFold
metadata independent of Markdown rendering.

## Changes

- Open ProofFold documents when `notation.yaml`, `references/`, or their manifest
  fields are absent. These authoring resources are not required to render a
  document.
- Use `folds/` when `foldsDirectory` is omitted. The directory can be absent when
  the document has no folds yet.
- Render the document as ordinary Markdown when its ProofFold manifest is
  malformed or unreadable. The same behavior applies during automatic reloads.
- Skip unavailable fold files and inaccessible subdirectories while keeping the
  entry and readable folds available.
- Add tests covering optional-resource combinations, minimal and invalid
  manifests, locked files, recovery, and actual Windows app rendering through
  `.md` and `.markdown` file associations.

## Install or upgrade

1. Install the Microsoft .NET 10 Desktop Runtime for Windows x64 and the Microsoft
   Edge WebView2 Runtime if they are not already available.
2. Download `ProofMD-2.0.2-win-x64.zip` and extract the complete folder.
3. Close ProofMD and LeanMD, then run `Install-ProofMD.cmd` in the extracted
   `ProofMD-2.0.2` folder. Installation is per-user and requires no administrator
   privileges.
4. Open ProofMD. Existing settings and Windows default-app choices are preserved.
