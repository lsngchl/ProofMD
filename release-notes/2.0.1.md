# ProofMD 2.0.1

ProofMD 2.0.1 fixes opening ProofFold documents before their folds directory
exists and improves Windows file associations when upgrading the app.

## Changes

- Open ProofFold entry documents with an empty fold collection when the configured
  folds directory is missing. The entry remains readable even when it links to a
  fold that has not been created yet.
- Update the displayed document and fold map when the first fold is added or the
  folds directory is removed.
- Repair Markdown file associations left by an earlier upgrade while preserving
  Windows default-app choices and settings.
- Show ProofMD's name and icon in Open With, Default Apps, and the Start Menu.
  Clean up obsolete app history and compatibility registrations after the user
  selects a new default app.
- Add regression tests for missing fold directories and installer upgrades.

## Install or upgrade

1. Install the Microsoft .NET 10 Desktop Runtime for Windows x64 and the Microsoft
   Edge WebView2 Runtime if they are not already available.
2. Download `ProofMD-2.0.1-win-x64.zip` and extract the complete folder.
3. Close ProofMD and LeanMD, then run `Install-ProofMD.cmd` in the extracted
   `ProofMD-2.0.1` folder. Installation is per-user and requires no administrator
   privileges.
4. Open ProofMD. Existing settings are preserved.

To update a Markdown default still named LeanMD in Windows, select ProofMD in the
file's **Open with** dialog and choose **Always**.
